# 剪贴板 Clipboard

独立的 macOS 菜单栏剪贴板历史工具，使用 Swift 和 AppKit。支持 macOS 14+、Apple Silicon。
Bundle ID：`com.zhuzhongqian.clipboard`。本目录是独立 Git 仓库，与同级 zhuomian 应用互不依赖。

## 构建与运行

需要 Apple Command Line Tools（`xcode-select --install`），无第三方依赖。

```sh
git clone https://github.com/Sunrisies/clipboard.git
cd clipboard
bash Scripts/make_app.sh
open build/Clipboard.app
```

菜单栏出现剪贴板图标，没有 Dock 图标。发布优化构建使用 `bash Scripts/make_app.sh release`。
默认使用本地 ad-hoc 签名；如需证书签名，可设置 `CLIPBOARD_SIGNING_IDENTITY`。
此版本用于本机运行，尚未进行 Developer ID 公证或安装包分发。
设置页会显示版本号、构建号、构建时间和源码修订号。需要指定发布版本时，设置 `CLIPBOARD_VERSION` 与 `CLIPBOARD_BUILD_NUMBER` 后构建。当前仓库没有发布更新源，因此“检查更新”会说明无法在线比较。

## 使用

- 复制文本后自动记录；完整文本去重，重复记录移到顶部，保留原始换行和空格。
- 支持剪贴板 PNG/TIFF/JPEG/HEIC/GIF 图片和 Finder 复制的图片文件，显示缩略图和尺寸，选中后可预览、复制并粘贴到支持图片的应用。图片统一保存为 PNG，保留透明度；重复图片按规范化 PNG 内容去重。
- 默认 **⌘⇧V** 打开或关闭历史窗口；可在菜单栏的“设置…”中录制新快捷键。注册冲突时保留旧快捷键并显示错误。
- 搜索支持中文和忽略大小写；**↑↓** 选择、**Return** 复制并关闭、**Esc** 关闭、**⌘F** 搜索。也可双击记录或点击复制按钮；列表聚焦时支持 **⌘C**。
- 搜索框支持 **⌘V** 粘贴、**⌘A** 全选及标准文本编辑快捷键。
- 复制后回到先前应用，用 **⌘V** 粘贴。第一版不自动发送粘贴按键。
- 菜单栏可暂停/恢复记录；暂停状态重启后保留，暂停期间的复制不会补录。
- “清空历史…”确认后删除全部本机记录，保留系统剪贴板当前内容。
- 默认 200 条，可设为 50 / 100 / 200 / 500 / 1000 条。降低上限立即删除最旧记录。
- 设置中的“开机自启（登录后启动）”使用 macOS 登录项服务，默认不主动开启。状态以系统为准；需要批准时，可通过“系统登录项…”打开系统设置。登录后在菜单栏运行，不主动展示历史内容。
- 打开设置时隐藏历史面板，关闭设置后历史保持隐藏；通过菜单或快捷键再次打开历史。
- 每次唤起默认显示“历史记录”。顶部可切换到“常用文本”，支持新增、编辑、删除、按名称或正文搜索，以及键盘选择和复制完整正文。名称可选，留空时自动取正文首行。
- 历史中的文本可点击“存为常用文本”保存；常用文本独立存储，清空历史、暂停记录、历史容量淘汰均不删除常用文本。复制常用文本时，未暂停的情况下仍会正常加入剪贴板历史。

搜索“图片”或 `image` 可筛选图片，也可按图片尺寸搜索。暂不支持图片 OCR 或动图播放。

## 本机数据

历史索引存储在 `~/Library/Application Support/com.zhuzhongqian.clipboard/history.json`，图片保存在同目录的 `images/` 中，设置由本应用的 UserDefaults 保存。已有文本历史可直接加载。
常用文本保存在同目录的 `snippets.json`，以原子方式写入且权限为 `0600`。单条正文最多 100 KiB、名称最多 120 个字符；最多 1000 条，总量上限 20 MiB，达到上限时显示错误，不自动删除常用文本。
不联网、不使用 iCloud、不写入 zhuomian 的数据或设置。历史文件以原子方式写入，权限为 `0600`，目录权限为 `0700`。
索引是明文 JSON，图片是 PNG；未实现加密。图片文件权限为 `0600`。遇到损坏文件会显示错误并保留原文件，避免覆盖。容量淘汰及清空历史会删除相应图片文件。

单条文本最多 100 KiB，单张图片最多 5 MiB（规范化 PNG）/ 2000 万像素，原始图片输入最多 100 MiB；超出不记录。文本和图片合计最多 20 MiB，超出时淘汰最旧记录（索引元数据另计）。条数上限由文本和图片共同使用。
忽略空白文本、不支持的内容以及带有常见 Concealed / Transient / AutoGenerated 标记的剪贴板内容。图片与文本同时存在时优先记录图片。仅在用户从 Finder 明确复制图片文件时读取其内容，并遵守同一张数、文件大小和像素限制；不会读取其他类型的文件。
应用每 0.5 秒检查一次剪贴板变化；非常短时间内的连续复制可能只捕获最后一条。启动前的剪贴板内容不会自动导入。
快捷键使用 Carbon 注册，无需辅助功能或屏幕录制权限。
